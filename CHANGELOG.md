# Changelog

## [1.0.0] — 2026-06-07

### Added
- Initial release: elemental ring game with 8 element segments
- Interactive ring visualization with tap-to-select
- Segment detail cards with level, progress bar, abilities
- Experience and leveling system (RingEngine)
- In-memory progress store with Flow-based reactive state
- 3 test classes covering engine, store, and models (20+ test cases)
- Gradle version catalog (libs.versions.toml)
- Android CI/CD pipeline (GitHub Actions)
- ProGuard rules for minification
- Kotlin Multiplatform project structure (shared + composeApp)
